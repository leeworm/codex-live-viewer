# Codex Live Viewer 0.5.4

이 패키지는 기존 Codex 실행 스트림을 관찰하여 해당 대화의 내장 브라우저 패널에 코드·diff·명령 진행 상황을 표시합니다. 별도 모델 실행이나 앱 바이너리 패치를 하지 않습니다.

Enable-Auto.cmd: 사용자 AppData에 검증된 번들을 복사하고 CODEX_CLI_PATH를 등록합니다. 이후 Codex를 정상 종료한 뒤 기존 아이콘으로 실행하면 자동 연결됩니다. 실행 중인 앱을 강제 종료하지 않습니다. Disable-Auto.cmd는 직전 사용자 설정을 복구합니다.

수신 코드는 타이핑 효과로 표시되며, 줄 더 보기로 펼칠 수 있습니다. 위로 스크롤하면 자동 스크롤이 멈추고, 하단 중앙의 복귀 버튼으로 최신 작업을 따라갈 수 있습니다. 색상은 Codex 앱 테마를 따릅니다.

지원 범위: Windows의 로컬 Codex 실행. 업데이트 후 CLI 연결 설정과 기본 open_in_codex 도구 계약이 유지되어야 합니다. 원격·서비스 전용 실행 및 모든 미래 버전과의 호환을 보장하지 않습니다.

이 소스에 포함된 선택적 훅 플러그인은 실제 executor 메타데이터와 기존 이벤트의 소유권을 대조합니다. 플러그인 신뢰 검토를 우회하지 않습니다. 자동 표시 자체는 훅 없이도 작동합니다.

원본 소스, 빌드 방법과 검증 범위: https://github.com/leeworm/codex-live-viewer
