# Codex Live Viewer 0.5.4

이 패키지는 기존 Codex 실행 스트림과 플러그인 훅을 관찰하여 내장 브라우저 탭이 아닌 **Codex 플러그인 패널(`ui://codex-live-viewer/panel.html`, `text/html;profile=mcp-app`)** 에 코드·diff·명령 진행 상황을 표시합니다. 별도 모델 실행이나 앱 바이너리 패치를 하지 않습니다.

`Enable-Auto.cmd`는 현재 폴더를 고정 설치 위치로 등록하고, Codex의 정식 플러그인 등록 명령과 로컬 MCP 연결을 설정합니다. 사용자 Codex 지침에는 코드 작업 전 자동 호출 규칙을 추가합니다. 설정을 백업하고 기존 지침을 보존하며, 브라우저 자동 열기는 비활성화합니다. 처음 연결한 뒤 Codex를 정상 종료하고 기존 아이콘으로 다시 실행합니다.

`Disable-Auto.cmd`는 이전 CLI 연결을 복구하고 MCP 연결·플러그인·자동 호출 규칙을 해제합니다. 활성화된 폴더는 이동하거나 삭제하지 마세요.

수신 코드는 타이핑 효과로 표시되며, 줄 더 보기로 펼칠 수 있습니다. 위로 스크롤하면 자동 스크롤이 멈추고, 하단 중앙의 복귀 버튼으로 최신 작업을 따라갈 수 있습니다. 색상은 Codex 앱 테마를 따릅니다.

지원 범위는 Windows의 로컬 Codex 실행, MCP App 플러그인 패널과 실시간 `app-server` 스트림 연결입니다. 코드 변경 전에 열린 뷰어 탭을 먼저 확인하고, 이미 있으면 그대로 사용합니다. UI 도구가 없는 보조 작업자는 패널을 열지 않습니다.

원본 소스, 빌드 방법과 검증 범위: https://github.com/leeworm/codex-live-viewer
