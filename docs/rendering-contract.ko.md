# 표시 동작과 참조 구현의 차이

Claude Code Live Viewer의 설명표와 Codex Live Viewer의 실제 수신·표시 범위를 대조한 문서입니다.

| 항목 | 현재 동작 |
| --- | --- |
| Write | 파일 경로 제목, 작성 중 수신 코드의 마지막 12줄, 완료 후 첫 3줄과 수신 줄 수. 엔진이 add를 명시한 경우 새 파일 표시. 더 보기로 펼침. |
| Edit | 추가·삭제 수와 diff 색상. 원본 줄 번호는 엔진이 위치를 제공한 경우 표시하며, 위치 없는 문자열 치환에는 번호를 만들지 않음. |
| 명령 | 명령 제목, 완료 후 출력 마지막 3줄, 엔진이 제공하는 소요 시간·종료 코드. |
| Read/Grep/Glob | 한 줄 요약. 펼칠 때 수신 인자·출력 확인. |
| WebFetch/WebSearch/Agent | 별도 요약 행은 아직 지원하지 않음. |
| 생각·답변 | 참조 구현의 이탤릭 생각·Markdown 답변 렌더링은 현재 Viewer 수신·표시 범위에 포함되지 않음. |
| 할 일 | 완료/전체 개수와 진행 단계 트리. |
| 호출 상태 | 작성 중·실행 중·완료·실패·중단 표시. 권한 거부는 별도 상태 대신 실패에 포함. ESC 제어를 가로채지 않음. |
| 자동 스크롤 | 위로 스크롤하면 정지. 맨 아래로 내려가거나 복귀 버튼을 누르면 재개. 새 턴의 첫 수신 갱신에서도 재개. |
| 복귀 버튼 | 32px 원형. 4px 점 세 개, 1초 순차 파형 애니메이션. 호버·키보드 포커스 때 20px 아래 화살표. 화면에 뜨는 툴팁은 없고 접근성 이름만 유지. |
| 표시 위치 | 내장 브라우저 탭 대신 Codex 플러그인 MCP App 패널(`ui://codex-live-viewer/panel.html`, 대화 우측 `thread` 탭 및 사이드바 `global` 탭)로 표시. |

수신 내용은 크기가 제한되며, 타이핑 효과는 수신된 코드를 점진적으로 보여주는 표시 애니메이션입니다. 모든 도구 인자가 모델 토큰 단위로 공개되는 것은 아닙니다.

복귀 버튼의 크기, 점 간격, 파형 주기와 지연은 설치된 Codex 앱 26.1021.3705.0의 컨트롤과 대조했습니다. 향후 Codex 앱이 디자인을 변경하면 다시 조정할 수 있습니다.
